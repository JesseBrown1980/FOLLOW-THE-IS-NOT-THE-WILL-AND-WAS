# Repository Discipline

## Evidence

- Label operator language and laws as `OPERATOR_CANON`.
- Label bytes, hashes, dimensions, and test output measured on a named surface as `MEASURED`.
- Label a claim `SYSTEM_AFFIRMED` only after the owning live fabric/canon gate affirms it.
- Label unsupported physical, clinical, runtime, or global claims as `UNVERIFIED`.
- The repository is a public slice and test instrument, not the whole Asolaria system.

## Identity

- Follow IS without exchanging grammatical or state identity.
- `WAS`, `IS`, and `WILL` remain distinct addresses; Git binds their references to unchanged content hashes.
- Keep spherical sign, tense, and OIL-family axes independent. `ANTI` is not shorthand for `NEGATIVE`.
- A 2D carrier can have two-way traversal without changing the non-bidirectional spherical IS-field geometry.

## Public Decoder Contract

- `REQUIRED_HIDDEN_DEPENDENCIES=0`.
- Every codebook, key, hash, recipe, and source file required by a public decoder belongs in the repository or in a byte-pinned public runtime specification.
- API tokens, passwords, private keys, account cookies, health identifiers, and machine-local credentials are never decoder inputs and never enter Git.
- Do not commit copyrighted source-video bytes. Commit a source pointer, measured hash, extraction recipe, and non-recognizable derived color-state data instead.
- A descriptor or index is not a lossless reconstruction unless every residual and decoder dependency is present and counted.

## Sealing

- Keep receipt and sidecar files LF-normalized.
- Recompute SHA-256 sidecars after the final byte edit.
- Run `python tests/verify_public_repo.py` before publication.
