# FOLLOW-THE-IS-NOT-THE-WILL-AND-WAS

This is the public, hash-addressed test ground for the Book of Knowledge: follow the
IS and preserve every WAS and WILL reference without exchanging their identities.
Its public decoder contract is exact:

```text
REQUIRED_HIDDEN_DEPENDENCIES=0
```

All keys, codebooks, hashes, recipes, and source code required to interpret a
published artifact are public. Account credentials are not decoder keys and are
never part of this repository.

## What is grounded here

- `OPERATOR_CANON`: the book sequence, IS language, spherical coordinates, and
  Jesse Brown Sphere statement recorded in `knowledge/`.
- `MEASURED`: the authorized 821,531-byte IS photo, its SHA-256, the pinned
  GitRAM/NEST/SGRAM source bytes, and repository verification output.
- `UNVERIFIED`: any physical, biological, clinical, global-performance, or
  live-runtime inference not established by its owning evidence gate.
- `SYSTEM_AFFIRMED`: intentionally absent until a current owning fabric/canon
  surface affirms a specific claim. Repository files are public slices, not that
  live authority.
